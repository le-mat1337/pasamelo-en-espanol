# Seguridad

Si encontrás una vulnerabilidad (una forma de saltear los cupos, de hacer que el servidor pida algo a un host que no corresponde, de ejecutar código, de filtrar secretos o de gastarnos plata), **no abras un issue público**.

Usá "Report a vulnerability" en la pestaña Security de este repo (GitHub Private Vulnerability Reporting). Contestamos en una semana como mucho.

Fuera de alcance: que Instagram o TikTok bloqueen las descargas, el rate limiting del WAF de Vercel y ataques que requieren acceso a la cuenta de Vercel.

Las capas de seguridad están resumidas en el README.
